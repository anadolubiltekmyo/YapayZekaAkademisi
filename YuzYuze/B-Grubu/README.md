**Grup:** Lisans & Ön Lisans
**Tarih:** 13 – 14 Nisan 2026
**Ders Saati:** 17:00 – 20:00
**Toplam Süre:** 6 saat (2 oturum)
**Eğitmen:** Öğr. Gör. Güvenç Usanmaz

---

## 🎯 Haftanın Hedefleri

Bu haftanın sonunda katılımcılar:
- Full-stack bir web uygulamasının mimarisini kavrayacak ve sıfırdan kurabilecek
- Vibe coding yaklaşımıyla (Cursor / Bolt / Replit) CRUD uygulaması geliştirebilecek
- REST API kullanımını ve OpenAI / Gemini API entegrasyonunu bir projeye ekleyebilecek
- Geliştirici bağlamında ileri prompt tekniklerini (sistem promptları, ajan persona, debug) uygulayabilecek
