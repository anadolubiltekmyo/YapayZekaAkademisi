Dinamik Web Uygulaması Yayınlama Sorunu Deploying Dynamic Web Apps

Statik bir web sitesi (sadece HTML/CSS/JS) yayınlamak kolaydır — GitHub Pages'e yüklersiniz, biter. Ama dinamik bir web uygulaması (backend + veritabanı + API) yayınlamak çok daha zordur. Çünkü artık işin içinde sürekli çalışan bir sunucu vardır.

Nereye yüklenir?GitHub Pages, NetlifyVPS, Bulut platformu
VeritabanıYokVar (PostgreSQL, MongoDB…)
MaliyetÜcretsizGenellikle ücretli
Zorluk⭐ Kolay⭐⭐⭐⭐ Zor

Kendi Bilgisayarımı Sunucu Olarak Kullanamaz mıyım?

Teorik olarak evet, ama pratikte çok sorunludur:

  • Dinamik IP adresi: Ev internet bağlantınızın IP adresi sürekli değişir. Bugün 85.107.x.x iken yarın başka olur. Kullanıcılar sizi bulamaz.
  • Stabilite: Bilgisayarınız 7/24 açık olmalı. Elektrik kesintisi? Bilgisayar çökmesi? Windows güncellemesi? → Siteniz çöker.
  • İnternet hızı: Ev internet bağlantılarında upload hızı çok düşüktür (genellikle 5-10 Mbps). 50 kullanıcı bile sitenizi yavaşlatır.
  • Güvenlik: Ev bilgisayarını internete açmak güvenlik riski taşır.
  • ISP kısıtlamaları: Çoğu internet servis sağlayıcı, ev bağlantısında sunucu çalıştırmayı yasaklar.
🛑 Sonuç: Kendi bilgisayarınızı sunucu olarak kullanmak, ödev veya denemeler için olabilir ama gerçek bir uygulama için asla uygun değildir. Bunun yerine VPS veya bulut platformları kullanılır.

Peki Ne Yapacağız?

İki ana yol var:

  1. Klasik yol — VPS: Bir sanal sunucu kiralayıp Linux komutlarıyla her şeyi kendiniz kurmak (zor ama tam kontrol)
  2. Kolay yol — Docker + Bulut: Uygulamayı Docker ile paketleyip Fly.io, Railway gibi platformlara yüklemek (çok daha basit)

🌐 Domain ve SSL Ayarları

İşler burada daha da karmaşıklaşır:

  1. Domain satın al (NameCheap, Google Domains, Turhost… — yıllık ~$10-15)
  2. DNS ayarlarını yap — Domain'in A kaydını sunucu IP'sine yönlendir
  3. Nginx reverse proxy kur — 80/443 portunu uygulamanıza yönlendir
  4. SSL sertifikası al — Let's Encrypt ile ücretsiz (certbot)
# SSL sertifikası alma (Let's Encrypt)
$ sudo apt install certbot python3-certbot-nginx
$ sudo certbot --nginx -d myapp.com -d www.myapp.com
Congratulations! Your certificate and chain have been saved.
⚠️ VPS Zorluğu Özeti: Sadece "uygulamamı internete koymak" için: Linux komutları + SSH + dosya aktarımı + program kurulumu + servis yönetimi + domain + DNS + Nginx + SSL öğrenmek gerekiyor. Programcı olmayanlar için bu duvar oldukça yüksek!

Kolay Yol: Docker ve Bulut Deploy Docker & Cloud Deployment

VPS kurmak çok iş. Peki daha kolay bir yol yok mu? Var: Docker ile uygulamanızı paketleyip, bulut platformlarına tek komutla yüklemek.

Docker Nedir?

Docker, uygulamanızı tüm bağımlılıklarıyla (Node.js, Python, veritabanı…) birlikte bir konteyner (kutunun içine paketler gibi) haline getirir. Bu pakete Docker image (imaj) denir.

Düşünün ki bir taşınma kutusu hazırlıyorsunuz — içine uygulamanızı, Node.js'i, tüm npm paketlerini, .env dosyanızı koyuyorsunuz. Bu kutuyu herhangi bir bilgisayara götürüp açtığınızda uygulama hemen çalışıyor.

Dockerfile Örneği

# Dockerfile — uygulamanızı paketleme tarifi
FROM node:22-alpine          # Temel: Node.js 22 yüklü küçük Linux

WORKDIR /app                  # Çalışma klasörü

COPY package*.json ./         # Önce paket dosyalarını kopyala
RUN npm install               # Bağımlılıkları kur

COPY . .                      # Tüm uygulama kodunu kopyala

EXPOSE 3000                   # Port 3000'i aç
CMD ["node", "server.js"]     # Uygulamayı başlat
🎯 AI ile Dockerfile Oluşturma: Dockerfile yazmayı bilmenize gerek yok! AI'a "Express uygulam için Dockerfile oluştur" deyin, size hazırlar. Hatta projenin tüm dosyalarını verip "bunu deploy edilebilir hale getir" demeniz yeterli.

"Express.js backend uygulamam var. Bu uygulamayı Docker ile paketlemek istiyorum. Dockerfile, .dockerignore ve gerekli tüm yapılandırmayı oluştur. Uygulama port 3000'de çalışıyor ve .env dosyasından environment variable okuyor."

Docker Komutları (Temel)

# Docker imajı oluştur
$ docker build -t myapp .

# Konteyneri çalıştır
$ docker run -p 3000:3000 --env-file .env myapp

# Çalışan konteynerleri listele
$ docker ps

# Konteyneri durdur
$ docker stop container_id

Web Servisi ve API Nedir? Web Services & APIs

Bir web servisi, internet üzerinden erişilebilen bir yazılım hizmetidir. Hava durumu verisi, döviz kurları, harita bilgisi, ödeme işleme — bunların hepsi birer web servisidir. Siz kendi uygulamanızdan bu servislere API (Application Programming Interface) aracılığıyla bağlanırsınız.

LLM sağlayıcıları (OpenAI, Google, Anthropic…) da birer web servisidir. ChatGPT web sitesine gittiğinizde aslında tarayıcınız arka planda OpenAI API'sine istek gönderir. Siz de kendi uygulamanızdan aynı API'yi çağırabilirsiniz!

API İletişimi Nasıl Çalışır?

Neredeyse tüm modern API iletişimi şu düzende çalışır:

  1. Uygulamanız bir HTTP isteği gönderir (genellikle POST)
  2. İstek bir URL (endpoint) adresine gider
  3. İstek başlığında (header) API anahtarınız bulunur
  4. İstek gövdesinde (body) verileriniz JSON formatında gönderilir
  5. Sunucu yanıtı yine JSON olarak döner
// Genel yapı — tüm LLM API'leri buna benzer
const yanit = await fetch("https://api.ornek.com/v1/chat", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "Authorization": "Bearer API_ANAHTARINIZ"    // Kimlik doğrulama
  },
  body: JSON.stringify({
    model: "model-adi",
    messages: [
      { role: "user", content: "Merhaba!" }     // Kullanıcı mesajı
    ]
  })
});
const veri = await yanit.json();
console.log(veri.choices[0].message.content);    // AI'ın yanıtı
💡 Neden API Kullanıyoruz? ChatGPT sitesinde zaten konuşabiliyoruz, neden API'ye ihtiyaç var? Çünkü API ile:
• Kendi uygulamanıza AI özelliği ekleyebilirsiniz (chatbot, öneri sistemi…)
• Yüzlerce isteği otomatik gönderebilirsiniz (toplu veri işleme)
• Kullanıcılarınıza AI destekli hizmet sunabilirsiniz
• Sistem promptu ve ayarlarla AI'ın davranışını kontrol edebilirsiniz

OpenAI API Kullanımı OpenAI API

OpenAI API, ChatGPT'nin arkasındaki GPT modellerine programatik erişim sağlar.

Kurulum

$ npm install openai

Temel Kullanım (Node.js)

import OpenAI from 'openai';

const openai = new OpenAI({
  apiKey: process.env.OPENAI_API_KEY  // .env dosyasından
});

const yanit = await openai.chat.completions.create({
  model: "gpt-4.1-mini",             // Hızlı ve ucuz model
  messages: [
    { role: "system", content: "Sen yardımcı bir asistansın." },
    { role: "user",   content: "JavaScript'te dizi sıralama nasıl yapılır?" }
  ],
  temperature: 0.7,                   // Yaratıcılık (0=katı, 1=yaratıcı)
  max_tokens: 500                     // Maksimum yanıt uzunluğu
});

console.log(yanit.choices[0].message.content);

Önemli Parametreler

ParametreNe İşe Yarar?Varsayılan

messagesSohbet geçmişi (system, user, assistant rolleri)—
temperature0 = deterministik, 1 = yaratıcı1
max_tokensYanıtın maksimum uzunluğuModel limiti

Streaming (Akış) — ChatGPT Efekti

const stream = await openai.chat.completions.create({
  model: "gpt-4.1-mini",
  messages: [{ role: "user", content: "Kısa bir hikaye yaz" }],
  stream: true                        // Kelime kelime akar
});

for await (const parca of stream) {
  const metin = parca.choices[0]?.delta?.content || "";
  process.stdout.write(metin);        // Ekrana anında yaz
}

💡 OpenAI Uyumlu API: Groq'un API formatı OpenAI ile aynıdır. Kodunuzda sadece base URL ve API key'i değiştirerek OpenAI → Groq geçişi yapabilirsiniz. Aynı şey birçok sağlayıcı için de geçerlidir (Together AI, Fireworks, OpenRouter…).

OpenAI SDK ile Groq Kullanma

import OpenAI from 'openai';

// Aynı OpenAI kütüphanesi, farklı endpoint!
const groq = new OpenAI({
  apiKey: process.env.GROQ_API_KEY,
  baseURL: "https://api.groq.com/openai/v1"
});

const yanit = await groq.chat.completions.create({
  model: "llama-3.3-70b-versatile",

LLM'i Web Uygulamasına Entegre Etme LLM Web Integration

LLM API'sini web uygulamanıza entegre ederken en kritik kural: API çağrılarını backend'den yapın. Frontend'e API anahtarı koymak = anahtarınızı herkese vermek demektir.

Doğru Mimari

Kullanıcı (Tarayıcı)
    │
    │ 1. "Şu soruyu sor" → POST /api/chat
    ▼
Backend (Express.js)
    │
    │ 2. API anahtarı ile → OpenAI/Gemini/Ollama
    ▼
LLM Sağlayıcı
    │
    │ 3. Yanıt (JSON)
    ▼
Backend → 4. Kullanıcıya JSON yanıt döner

Tam Örnek: Express + OpenAI Chatbot

Backend (server.js)

import express from 'express';
import OpenAI from 'openai';
import cors from 'cors';

const app = express();
app.use(cors({ origin: "http://localhost:5173" }));
app.use(express.json());

const openai = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });

app.post('/api/chat', async (req, res) => {
  try {
    const { mesaj } = req.body;
    const yanit = await openai.chat.completions.create({
      model: "gpt-4.1-mini",
      messages: [
        { role: "system", content: "Türkçe cevap ver. Kısa ve öz ol." },
        { role: "user", content: mesaj }
      ]
    });
    res.json({ cevap: yanit.choices[0].message.content });
  } catch (hata) {
    res.status(500).json({ hata: "Bir sorun oluştu." });
  }
});

app.listen(3000);

Frontend (React bileşeni — kısaltılmış)

const [mesaj, setMesaj] = useState("");
const [cevap, setCevap] = useState("");

async function gonder() {
  const yanit = await fetch("http://localhost:3000/api/chat", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ mesaj })
  });
  const veri = await yanit.json();
  setCevap(veri.cevap);
}

"React + Express ile bir AI chatbot uygulaması yap. Backend'de OpenAI API kullan. Sohbet geçmişi tutulan, streaming destekli (kelime kelime akan yanıt), modern görünümlü bir chat arayüzü olsun. Mesajlar yerel olarak saklanmasın, sadece oturumda kalsın."

⚠️ Sağlayıcı Değiştirme Kolaylığı: OpenAI SDK'sını kullanıyorsanız, sadece baseURL ve apiKey değiştirerek Groq, Ollama, Together AI gibi sağlayıcılara geçiş yapabilirsiniz. Kodunuzun geri kalanı aynı kalır!

Tool Use (Fonksiyon Çağırma) Function Calling / Tool Use

Tool Use, LLM'in "Bunu yapamıyorum, ama şu fonksiyonu çağırırsak yapabiliriz" demesini sağlar. Örneğin AI hava durumunu bilmez — ama siz bir havaDurumunuGetir(sehir) fonksiyonu tanımlarsınız, AI gerektiğinde bunu çağırır.

Nasıl Çalışır?

  1. Siz kullanılabilecek "araçları" (tools) tanımlarsınız
  2. Kullanıcı bir soru sorar
  3. LLM, soruyu cevaplamak için bir araç çağırmaya karar verir
  4. Siz bu aracı gerçekten çalıştırırsınız
  5. Sonucu LLM'e geri gönderirsiniz
  6. LLM, sonucu kullanarak doğal dilde yanıt verir
const yanit = await openai.chat.completions.create({
  model: "gpt-4.1-mini",
  messages: [{ role: "user", content: "İstanbul'da hava nasıl?" }],
  tools: [{
    type: "function",
    function: {
      name: "hava_durumu_getir",
      description: "Belirtilen şehrin güncel hava durumunu getirir",
      parameters: {
        type: "object",
        properties: {
          sehir: { type: "string", description: "Şehir adı" }
        },
        required: ["sehir"]
      }
    }
  }]
});

// LLM yanıtı: "hava_durumu_getir" fonksiyonunu { sehir: "İstanbul" } ile çağır
// → Siz gerçek API'yi çağırırsınız → Sonucu LLM'e geri gönderirsiniz
// → LLM: "İstanbul'da şu an 18°C ve parçalı bulutlu."
💡 Tool Use Nerede Kullanılır? • Hava durumu, döviz kuru gibi güncel veri çekme
• Veritabanı sorgusu çalıştırma
• E-posta gönderme, bildirim oluşturma
• Hesaplama yapma, dosya okuma/yazma
• Dış API'lere istek gönderme

Structured Output: Yapılandırılmış Çıktı Structured Output

Normalde LLM serbest metin üretir. Ama uygulama geliştirirken genellikle belirli bir formatta (JSON, tablo…) veri almanız gerekir. Structured Output özelliği, LLM'in her zaman geçerli JSON üretmesini garanti eder.

Neden Gerekli?

Diyelim AI'dan bir ürün listesi istiyorsunuz. Serbest metin olarak "İşte ürünler: 1) Laptop — 25000 TL, 2) Mouse…" gibi yanıtlar gelir. Bunu programatik olarak parse etmek zordur. Ama JSON şeması tanımlarsanız:

const yanit = await openai.chat.completions.create({
  model: "gpt-4.1-mini",
  messages: [{
    role: "user",
    content: "3 popüler laptop öner. Her biri için isim, fiyat (TL) ve özellik ver."
  }],
  response_format: {
    type: "json_schema",
    json_schema: {
      name: "laptop_onerileri",
      schema: {
        type: "object",
        properties: {
          laptoplar: {
            type: "array",
            items: {
              type: "object",
              properties: {
                isim: { type: "string" },
                fiyat: { type: "number" },
                ozellik: { type: "string" }
              },
              required: ["isim", "fiyat", "ozellik"]
            }
          }
        },
        required: ["laptoplar"]
      }
    }
  }
});

// Garanti JSON çıktı:
// { "laptoplar": [
//   { "isim": "MacBook Air M3", "fiyat": 45000, "ozellik": "Hafif, uzun pil" },
//   ...
// ]}
🎯 Kullanım Alanları: • Veri çıkarımı (extraction): Metinden isim, tarih, adres çekme
• Sınıflandırma: Duygu analizi, kategori atama
• Veritabanına yazma: AI çıktısını doğrudan DB'ye kaydetme
• API entegrasyonu: AI çıktısını başka servislere gönderme
